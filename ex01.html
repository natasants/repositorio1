Selecionando os elementos DOM

Posso selecionar os elementos DOM: por marca (tagname); por ID; por classe; por seletor(CSS)

existem alguns comandos que nós vamos utilizar

Por marca (tagname)

o comando é o getElementsByTagName

Como esta no plural: getEements... eu preciso dizer o número do elemento que eu quero utilizar, lembrando que no JS a contagem dos elementos começa do zero.

Por ID

O comando é: getElementById

Preciso atribuir o ID na tag que eu quero manipular.

Por ClassName

o comando é: get ElementByClassName

Por seletor de CSS

O comando é querySelector

Se a tag que eu quero selecionar estiver com id, eu uso

Selecionando por name

O comando é getElementsByName
